# My Romantic Love Page

A simple romantic static webpage with a heart animation and solar-system style transformation.

## Files
- `folder.html` - main page
- `style.css` - styling and animations
- `script.js` - interactive JavaScript

## Preview locally
Open `folder.html` in your browser, or run a local web server in this folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Upload to GitHub
1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. Go to repository settings.
4. Open the "Pages" section.
5. Select the branch: `main` or `master`.
6. Save the settings.

## GitHub Pages link format
After publishing, your site will be available at:

```text
https://<your-github-username>.github.io/<your-repository-name>/
```

Example:

```text
https://johndoe.github.io/love-page/
```
